# RoleMesh - 校园角色匹配平台

一个面向校园场景的角色匹配与团队组队平台，帮助学生按「角色（Role）」快速找到合适的项目与队友。

## 项目结构

```
RoleMesh/
├── index.html                  # 前端主页面（单文件 demo，含全部页面与交互）
└── 字段交接-前端映射表.md        # 前后端字段映射说明（以前端字段名为准）
```

## 前端说明

- `index.html` 为单文件前端 demo，使用原生 HTML/CSS/JS 实现，无需构建即可在浏览器中打开预览。
- 覆盖页面：首页（项目推荐）、Mesh 匹配、项目详情、发起项目、消息、我的（个人画像）等。
- 当前为纯前端静态版本，数据为内置 mock，用于演示与 UI 走查。

## 字段映射

后端接口 DTO 命名请对齐 `字段交接-前端映射表.md` 中的「前端字段名」一列，该文档以 demo 实际使用的字段名为准，并标注了前端独有、契约缺失的字段（如 `mode`、`urgent`、`roleDuty`、`vibe`、`hot`、`matchRoles` 等），详见文档第七节「需要后端/产品最终确认的差异点」。

## 预览

直接用浏览器打开 `index.html`，或使用任意静态服务器：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```
