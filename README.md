# RoleMesh - 校园角色匹配平台

一个面向校园场景的角色匹配与团队组队平台，帮助学生按「角色（Role）」快速找到合适的项目与队友。

## 项目结构

```
RoleMesh/
├── index.html                        # 前端主页面（单文件 demo，含全部页面与交互）
├── HANDOVER.md                       # 交接说明：版本状态 / 变更记录 / Mock 与真实接口对照
├── README.md                         # 本文件
├── openapi.yaml                      # 接口草案（由前端 mock 反推，非后端既有定义）
├── 后端接口规格-由前端反推.md          # 接口清单与字段说明
├── 后端业务规则-状态机与校验.md        # 业务状态机与校验规则
├── 契约字段对齐表.md                   # 页面元素 ↔ 契约字段 逐项对齐
├── 需后端接口的动态数据清单.md          # 后端需要提供的动态数据清单
├── 前端字段交接表.md                   # 前端字段交接
├── 字段交接-前端映射表.md              # 前后端字段映射（以前端字段名为准）
├── 视觉规范-莫兰迪改版.md              # 视觉规范
└── 页面功能说明-大白话版.md            # 页面功能说明（非技术向）
```

## 前端说明

- `index.html` 为单文件前端 demo，使用原生 HTML/CSS/JS 实现，无需构建即可在浏览器中打开预览。
- 覆盖页面：登录 / 注册、首页（项目推荐）、Mesh 匹配、项目详情、发起项目、消息、我的（个人画像）等。
- 当前为纯前端静态版本，数据为内置 mock，用于演示与 UI 走查。

## 当前状态（重要）

- **已接入真实接口：0 个。** `index.html` 内没有任何 `fetch` / `XMLHttpRequest` / `axios` 调用，
  业务数据全部为文件内写死的数组，**刷新后所有操作都会重置**。
- **登录页是前端模拟的**：手机号 / 邮箱 + 验证码，验证码固定 `123456`；登录态只存在 `sessionStorage`，
  不是真实鉴权。也可以点「先逛逛」以游客身份进入。
- 接口草案见 `openapi.yaml`：27 个路径 / 32 个操作（含 4 个 `/auth/*`），全部未实现。
- 每个页面是 Mock 还是已接真实接口、每次改动改了什么，统一记录在 **`HANDOVER.md`** 里，联调前请先看它。



## 预览

直接用浏览器打开 `index.html`，或使用任意静态服务器：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```
